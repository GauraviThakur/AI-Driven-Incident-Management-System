# 📌 Project Overview

This project focuses on designing and implementing an AI-Driven Incident Management System using ServiceNow.

The system automates key ITSM processes such as incident assignment, SLA tracking, and notifications, while also providing intelligent knowledge base suggestions to assist in faster resolution.

## 🎯 Objectives

- Automate incident routing based on category
- Track resolution time using SLA policies
- Notify users through event-driven emails
- Suggest relevant knowledge articles for quick fixes
- Provide dashboard insights for monitoring incidents

## 💼 Real-World Use Case

This system simulates how IT support teams manage and resolve incidents efficiently in an organization.
