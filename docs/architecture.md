# 🧩 System Architecture

## 🔹 Components Used

- Incident Table (Core data storage)
- Assignment Rules (Routing logic)
- SLA Engine (Time tracking)
- Business Rules (Event triggering)
- Event Registry (Event handling)
- Notifications (Email alerts)
- Knowledge Base (Solution repository)
- Dashboard (Visualization)

## 🔹 Workflow

1. User creates an incident
2. Assignment rule assigns it to a group
3. SLA gets attached based on priority
4. Business Rule triggers event on assignment change
5. Notification is sent to assigned user
6. Knowledge Base suggests relevant articles
7. Dashboard tracks overall performance
